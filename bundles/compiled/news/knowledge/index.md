# Business Rule

* [AB Testing Cohort Analysis (ABTCA)](ab-testing-cohort-analysis.md) - Defines segmentation criteria for splitting users into cohorts for A/B testing experiments.
* [Content Consumption Consistency (CCC)](content-consumption-consistency.md) - Indicates uniformity in user content consumption behavior.
* [Content Recommendation Strategy (CRS)](content-recommendation-strategy.md) - Outlines the strategic framework used to select and rank recommended articles.
* [Content Virality Threshold (CVT)](content-virality-threshold.md) - Defines the performance level at which content is likely to go viral.
* [Conversion Potential Indicator (CPI)](conversion-potential-indicator.md) - Evaluates the potential of converting user interactions into conversions.
* [Engagement Consistency Principle (ECP)](engagement-consistency-principle.md) - States that consistent engagement across multiple sessions is a key indicator of long-term user loyalty.
* [High Engagement Indicator (HEI)](high-engagement-indicator.md) - Determines if a session or article demonstrates outstanding user engagement.
* [Interaction Timeliness Indicator (ITI)](interaction-timeliness-indicator.md) - Evaluates the promptness of user interactions after content presentation.
* [Network Connection Quality Standard (NCQS)](network-connection-quality-standard.md) - Defines the benchmark criteria for acceptable network performance to ensure reliable content delivery.
* [Performance Segment](performance-segment.md) - Categorizes sessions based on their relative bounce rate and CTR performance using percentile rankings.
* [Performance Status](performance-status.md) - Categorizes system records based on response time into Critical, Warning, or Normal bands.
* [Personalization Priority (PP)](personalization-priority.md) - Establishes criteria for prioritizing content that aligns closely with individual user preferences based on prior interactions.
* [Premium Article Distinction (PAD)](premium-article-distinction.md) - Classifies articles as premium based on quality and content policy adherence.
* [Premium Content Rule (PCR)](premium-content-rule.md) - Specifies that articles marked as Premium must meet higher quality and engagement benchmarks.
* [Readability Segmentation](readability-segmentation.md) - Classifies articles into readability categories based on calculated readability scores.
* [Readability Weight Mapping](readability-weight-mapping.md) - Defines difficulty-based weighting for readability calculations.
* [Session Drop-off Risk (SDR)](session-drop-off-risk.md) - Determines the likelihood of a session ending abruptly.
* [Short Session Anomaly Detection (SSAD)](short-session-anomaly-detection.md) - Identifies sessions with unusually short durations that may signal disengagement or testing anomalies.
* [Subscription Valuation Rule (SVR)](subscription-valuation-rule.md) - Determines the business value of a user by integrating subscription details with demographic and engagement factors.
* [System Resilience Factor (SRF)](system-resilience-factor.md) - Assesses the robustness and fault tolerance of the system.
* [Targeted Personalization Benchmark (TPB)](targeted-personalization-benchmark.md) - Establishes a benchmark for assessing the effectiveness of personalized content.
* [User Behavior Paradigm (UBP)](user-behavior-paradigm.md) - Describes typical patterns observed in user interactions within the platform.
* [User Churn Predictor (UCP)](user-churn-predictor.md) - Identifies users at risk of churning through behavior pattern analysis.

# Calculation

* [Adjusted Bounce Ratio (ABR)](adjusted-bounce-ratio.md) - Modifies the raw bounce metric by integrating real-time efficiency factors.
* [Adjusted Read Time Estimator (ARTE)](adjusted-read-time-estimator.md) - Provides an estimation of effective reading time by adjusting raw reading seconds.
* [Article Quality Index (AQI)](article-quality-index.md) - Determines the quality index of an article by integrating quality score, freshness, sentiment, and controversy factors.
* [Article Readability Score (ARS)](article-readability-score.md) - Calculates the readability of an article by correlating estimated reading time with word count and difficulty factor.
* [Bounce Percentile](bounce-percentile.md) - Ranks sessions by their adjusted bounce rate relative to all other sessions.
* [Cohort Percentage](cohort-percentage.md) - Calculates the proportional representation of each test group within monthly registration cohorts
* [Composite System Stability (CSS)](composite-system-stability.md) - Combines system and device performance to yield an overall stability measure.
* [Composite User Activity Score (CUAS)](composite-user-activity-score.md) - Integrates multiple user activity metrics into one composite score.
* [Content Interaction Efficiency (CIE)](content-interaction-efficiency.md) - Measures how efficiently a user interacts with content inside a session by looking at the average relative order in which events occur (their sequence values)
* [Conversion Impact Factor (CIF)](conversion-impact-factor.md) - Assesses the potential impact on conversions by linking engagement with prompt interaction.
* [CTR Percentile](ctr-percentile.md) - Ranks sessions by their click-through rate relative to all other sessions.
* [Dynamic Content Value (DCV)](dynamic-content-value.md) - Measures an article's overall value by combining quality, recommendation relevance, and readability factors.
* [Elite User Interaction Metric (EUIM)](elite-user-interaction-metric.md) - A newly defined metric to identify elite user interactions by combining session clicks, views, and engagement score.
* [Interactive Content Amplifier (ICA)](interactive-content-amplifier.md) - Enhances content value by factoring in user interactions and recommendation quality.
* [Optimized Recommendation Score (ORS)](optimized-recommendation-score.md) - Adjusts recommendation quality by incorporating system performance metrics.
* [Personalization Accuracy Metric (PAM)](personalization-accuracy-metric.md) - Computes the accuracy of personalization by balancing recommendation performance and priority assignment.
* [Real-Time Session Efficiency (RTSE)](real-time-session-efficiency.md) - Evaluates session efficiency by balancing interaction outcomes against bounce adjustments.
* [Recommendation Click-Through Rate (RCTR)](recommendation-click-through-rate.md) - Defines RCTR as the ratio of clicks to total recommendations.
* [Recommendation Relevance Score (RRS)](recommendation-relevance-score.md) - Computes the overall relevance of a recommendation by averaging recommendation score, algorithm confidence, and utility.
* [Session Bounce Rate Adjustment (SBRA)](session-bounce-rate-adjustment.md) - Adjusts the raw session bounce rate by factoring in the click-through rate to better understand session quality.
* [System Performance Index (SPI)](system-performance-index.md) - Measures overall system performance by considering response time, load, and performance scores.
* [User Demographic Score (UDS)](user-demographic-score.md) - Measures the impact of user demographics by combining age with factors related to gender and occupation.
* [User Engagement Rate (UER)](user-engagement-rate.md) - Calculates the engagement rate of a user during a session by combining engagement score, page views, and session duration.
* [User Subscription Value (USV)](user-subscription-value.md) - Evaluates the relative value of a user's subscription based on subscription duration and status.
